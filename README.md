# Aerobiotix — Creative Reference Link

Social Content Direction — Vol. 01

A single-page moodboard / social content direction site for **Aerobiotix** — medical-grade
clean-air technology built for healthcare and the operating theatre. Brand identity (purple
orbital-A mark, lavender-and-charcoal theme, PT Sans typography) taken from the Aerobiotix
brand guidelines; content pillars and reference links supplied by Inloop Media.

- **Type:** PT Sans (display + body + accents)
- **Palette:** lavender-white `#faf7fd` ground, Aerobiotix Purple `#560299` accent (Pantone — brand), Soft Lavender `#744FA5`, Coral `#DF796B` pop, charcoal text
- **Pillars:** Education · Technology · Credibility · OT Culture · FAQ / Objections
- **Grid:** 13 reference pieces (reels, statics + carousels) with pillar filters and a lightbox gallery
